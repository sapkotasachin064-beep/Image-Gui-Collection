Here’s the thing. I didn’t really put much effort into this menu. Like, at all.
I mean, sure, it works—kinda. But let’s be real, it’s basically just a bunch of
buttons, and checkboxes slapped together in like... what, 10 minutes?

Yeah, I kinda spent more time choosing what colors I should use for this. I
could’ve spent hours polishing it, adding animations, or making it look like
some cyberpunk UI from 2077. But nah. Not today. Maybe not ever. This menu is
the bare minimum, and I’m not ashamed to admit it.

So, if you’re expecting some masterpiece of code and design... uh, sorry to
disappoint. Enjoy the mediocrity!
